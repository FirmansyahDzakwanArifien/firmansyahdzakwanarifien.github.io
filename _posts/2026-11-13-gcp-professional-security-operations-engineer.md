## About the Certification

**Google Cloud Certified — Professional Security Operations Engineer** validates the ability to run security operations on Google Cloud: bringing security data into one place, writing detections, hunting for threats, and responding to incidents with automation. It is a professional-level certification, aimed at engineers who operate a SOC rather than only configure controls.

## What It Covers

- **Platform operations** — setting up and running Google Security Operations and Security Command Center, access control, and integrating Google Cloud and third-party sources.
- **Data management** — ingesting logs, parsing and normalizing them into the Unified Data Model (UDM), and enriching events with context.
- **Detection engineering** — writing and tuning YARA-L rules, using curated detections, and keeping false positives under control.
- **Threat hunting** — searching across security telemetry, pivoting on indicators, and using threat intelligence to find what rules missed.
- **Incident response** — case management, SOAR playbooks, and automating containment and remediation.
- **Observability** — dashboards, reporting, and monitoring the health of the security pipeline itself.
