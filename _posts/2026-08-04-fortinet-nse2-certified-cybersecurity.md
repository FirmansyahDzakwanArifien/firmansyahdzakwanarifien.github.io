## About the Certification

**Fortinet NSE 2 — Certified in Cybersecurity** builds on NSE 1 by introducing the security technologies used to counter the threats described at the first level. It is still vendor-neutral in spirit: the focus is on *what* each control does and where it sits in a defense-in-depth design.

## What It Covers

- **Network security** — firewalls and next-generation firewalls, intrusion prevention, secure SD-WAN.
- **Content and application security** — antivirus, web filtering, application control, and sandboxing for unknown threats.
- **Endpoint and access security** — endpoint protection, network access control, and secure remote access.
- **Cloud, email, and web application security** — the controls that protect workloads and services outside the traditional perimeter.
- **Security operations** — SIEM, SOAR, and centralized management as the glue that turns individual products into a coordinated defense.

## Why It Matters

NSE 2 is the map of the security stack. Knowing how the pieces fit together — and which control catches which class of threat — is what lets an analyst reason about gaps and coverage instead of treating each product as a black box. It directly supports my SOC and infrastructure work, where several of these controls are in daily use.
