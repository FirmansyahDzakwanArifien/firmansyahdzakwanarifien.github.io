Beyond headers
  • Subresource Integrity {{ site.data.sri.size }} third-party files pinned to SHA-384

    Every library loaded from jsDelivr carries a hash; if the CDN copy changes, the browser refuses it. CI fails when a hash goes stale.

  • No inline JavaScript enforced in CI

    All scripts are separate files, so the CSP needs no 'unsafe-inline'. The build fails on any inline script, on*= handler, or javascript: URL.

  • Self-hosted fonts and icons no Google Fonts requests

    Text fonts and a trimmed Font Awesome set are served from this domain, so visitors' IPs are not sent to a font CDN.

  • Pinned build pipeline Actions pinned to commit SHAs

    A moved or hijacked tag cannot change what runs in CI. Dependabot proposes updates weekly.

  • Vulnerability disclosure security.txt (RFC 9116)

    Tells researchers how to report a vulnerability. A weekly CI check fails 30 days before the file expires, so it never goes stale.
